# MoRaj Ledger — website

The public site for **MoRaj Ledger**, offline accounting software for Ghanaian
businesses, schools and NGOs. A product of MoRaj Systems & Supplies.

This repository holds the website only. The application source is private.

To publish a change: edit `index.html` in the private Suite repo at
`docs/landing.html`, copy it here as `index.html`, commit and push. GitHub Pages
serves it within a minute.
